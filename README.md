# E-Combo Landing Page

A responsive product landing page built with Next.js, TypeScript, Tailwind CSS, Radix UI, Embla Carousel, and AOS animations.

## Live Demo

- **Production:** [e-combo-landing-page.vercel.app](https://e-combo-landing-page.vercel.app)

## Local Development

```bash
npm install
npm run dev
```
